- **Editorial Portrait Frame**: Custom silhouette curvature with live availability badge.

### 2. My Foundation (Philosophy)
Five single-word foundational pillars:
- `01 / Simplicity` — *"Strip away the noise. The essential is always enough."*
- `02 / Curiosity` — *"I need to know what lies on the other side."*
- `03 / Story` — *"Facts inform. Stories transform."*
- `04 / Growth` — *"One step forward, every single day."*
- `05 / Impact` — *"What matters most is who you built it for."*

### 3. My 5-Step Process (Operating System)
An interactive click-to-expand system detailing how ideas transform into reality:
- `01 / Awareness` → Filter: *"Am I paying conscious attention, or reacting on autopilot?"*
- `02 / Subtraction` → Filter: *"What can I remove so that only the essential remains?"*
- `03 / The Root` → Filter: *"Am I solving the deep root cause, or playing on the surface?"*
- `04 / Purpose` → Filter: *"Would I still pour my heart into this if nobody was watching?"*
- `05 / Creation` → Filter: *"Does this create real, practical value and leave a positive mark?"*

## 🎨 Design System & Palette

- **Aesthetic**: Editorial Warm Monochrome with Brushed Gold Accents.
- **Background**: Canvas `#F8F6F0`, Card `#FFFFFF`, Deep Dark `#141416`.
- **Accent**: Muted Gold `#C5A25D`, YouTube Red `#FF0000`, Focus Emerald `#10B981`.
- **Typography**:
  - Headings: `Cormorant Garamond` (Google Fonts, serif, 300/400/500/600/italic)
  - Body & UI: `Plus Jakarta Sans` (Google Fonts, sans-serif, 300/400/500/600/700)
- **Zero Heavy Frameworks**: Pure HTML5 and Vanilla CSS for maximum performance, buttery smooth 60fps animations, and instantaneous load times.

## 🛠 Local Development & Preview

To run and preview any version locally:

```bash
# Clone the repository
git clone https://github.com/Harixomxsingh/portfolio.git
cd portfolio

# Run a local development server (using live-server, python, or npx)
npx -y live-server --port=5173 .

# Or view v2 directly:
npx -y live-server --port=5173 ./v2
```
